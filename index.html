A tensor compiler, written from scratch

A static-shape tensor IR, reverse-mode autodiff as a graph-to-graph transform, a float64 interpreter that defines what every program means, and, from milestone 2, lowering to WGSL compute kernels so a small model can train in the browser. No ML framework in the engine; PyTorch is used offline only, to write golden files.

The question: when does kernel fusion pay off on an integrated GPU, and when does it lose? That needs measured numbers, including the cases where fusion is neutral or slower. Fused kernels are only worth timing once they are known to compute the same thing as the unfused ones, so the first milestone is the reference everything is checked against. This page reports all four milestones, newest first: the fusion study (4), the transformer (3b), the MLP (3a), the GPU kernels (2), the hardening pass (1.5) and the reference (1). Nothing earlier has been removed: each milestone's record, failures and false alarms included, is further down, unchanged.
