What does an out-of-bounds storage read return on this adapter?

One kernel, OUT[i] = A[IDX[i]], with indices supplied at run time so the compiler cannot see they are out of range. WebGPU only promises that such a read returns some value without faulting (zero, or a value from somewhere in the binding); this page records which, on this adapter only. ?record=0 skips saving.
